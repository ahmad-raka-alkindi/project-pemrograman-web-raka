A. Pendahuluan

Praktikum ini melanjutkan aplikasi ResepKu dari Praktikum 6 dengan fokus pada List, Grid, Gambar, dan Asset di Flutter. Sebelumnya daftar resep hanya berisi teks dan huruf inisial. Pada praktikum ini aplikasi ditambah logo, font sendiri, foto resep dari internet (lengkap dengan loading state dan error state), serta tampilan resep sebagai list maupun grid yang dapat dipilih dengan satu tombol. Fitur favorit dari Praktikum 6 tetap berfungsi di semua tampilan. Konsep dan widget utama yang dipelajari meliputi:

a. Asset & Custom Font

File gambar dan font yang ikut ter-bundle ke dalam aplikasi. Keduanya didaftarkan di pubspec.yaml, lalu dipakai dengan Image.asset dan fontFamily pada ThemeData.

b. Image.network

Menampilkan gambar dari URL internet. Karena koneksi bisa lambat atau putus, wajib dilengkapi loadingBuilder, errorBuilder, dan cacheWidth untuk menghemat memory.

c. ListView.builder

Daftar satu kolom yang membuat item secara lazy, yaitu hanya saat dibutuhkan, sehingga efisien untuk data yang banyak.

d. GridView.builder

Daftar beberapa kolom yang diatur melalui gridDelegate (jumlah kolom, jarak antar item, dan rasio ukuran). Item juga dibuat secara lazy.

B. Tujuan

Setelah menyelesaikan praktikum ini, mahasiswa mampu:

  1. Mendaftarkan asset gambar dan custom font di pubspec.yaml, lalu menggunakannya dengan Image.asset dan ThemeData.
  2. Menampilkan gambar dari internet dengan Image.network beserta loading state dan error state.
  3. Menampilkan data dengan ListView.builder dan GridView.builder.
  4. Mengganti tampilan list dan grid dengan state lokal (setState) tanpa mengganggu state favorit di Provider.

LANGKAH 5: PERTANYAAN ANALISIS
1. Mengapa status favorit tetap sama ketika tampilan berganti dari grid ke list, padahal RecipeGridCard dan RecipeTile adalah widget berbeda?

Status favorit tidak disimpan di dalam salah satu widget, melainkan di FavoriteProvider (ChangeNotifier) sebagai state global yang disediakan MultiProvider di atas MaterialApp sejak Praktikum 6. RecipeGridCard dan RecipeTile sama-sama membaca data dari satu sumber yang sama dengan context.watch<FavoriteProvider>().isFavorite(recipe) dan sama-sama mengubahnya lewat context.read<FavoriteProvider>().toggle(recipe). Ketika tampilan berganti, widget yang lama dibuang dan widget yang baru dibuat, tetapi data favorit tetap ada di provider sehingga ikon langsung mengikuti data tersebut. Seandainya favorit memakai state lokal seperti pada eksperimen Praktikum 6, status akan hilang karena ikut dibuang bersama widget-nya.

2. Apa yang tampil jika baris if (loadingProgress == null) return child; dihapus?

Yang tampil hanya kotak loading (ColoredBox dengan ikon restaurant_menu) selamanya, sedangkan foto tidak pernah muncul. Alasannya, loadingBuilder dipanggil terus, termasuk setelah unduhan selesai (saat itu loadingProgress bernilai null). Nilai yang dikembalikan loadingBuilder itulah yang ditampilkan menggantikan gambar. Tanpa baris tersebut, builder selalu mengembalikan widget loading dan tidak pernah mengembalikan child yang berisi foto yang sudah selesai diunduh.

3. Berapa pixel foto thumbnail yang di-decode dengan dan tanpa cacheWidth: 168, dan akibatnya untuk memory pada 50 resep?

Foto asli berukuran 1200 × 800 pixel. Tanpa cacheWidth, foto di-decode penuh: 1200 × 800 = 960.000 pixel. Dengan cacheWidth: 168, lebar menjadi 168 dan tinggi menyesuaikan proporsi (800 × 168 / 1200 = 112): 168 × 112 = 18.816 pixel. Jadi pixel yang di-decode berkurang sekitar 51 kali lipat (960.000 / 18.816 ≈ 51).

Dengan asumsi 4 byte per pixel (RGBA), satu foto tanpa cacheWidth memakai sekitar 3,84 MB, sedangkan dengan cacheWidth hanya sekitar 75 KB. Untuk 50 resep pada Praktikum 8, perbedaannya menjadi sekitar 192 MB berbanding sekitar 3,8 MB. Tanpa cacheWidth, aplikasi berisiko boros memory, scroll tersendat, bahkan ditutup paksa oleh sistem; dengan cacheWidth, memory tetap ringan walaupun data bertambah banyak.

Kondisi Pixel per foto Memory per foto (4 byte/pixel) Memory 50 foto
Tanpa cacheWidth 960.000 ± 3,84 MB ± 192 MB
Dengan cacheWidth: 168 18.816 ± 75 KB ± 3,8 MB
4. Mengapa logo memakai Image.asset dan foto resep memakai Image.network?

Logo sebaiknya tidak diambil dari internet karena ia adalah identitas aplikasi yang harus selalu tampil, termasuk saat tidak ada koneksi. Logo berukuran kecil, tetap, dan jarang berubah, sehingga cukup di-bundle ke dalam APK agar tersedia langsung tanpa menunggu unduhan dan tidak bergantung pada server. Sebaliknya, foto resep tidak dimasukkan ke asset karena jumlahnya banyak dan bertambah (50 resep pada Praktikum 8), ukurannya besar sehingga membuat APK membengkak, dan datanya berasal dari API sehingga dapat berubah tanpa harus memperbarui aplikasi. Untuk foto, kelemahan koneksi diatasi dengan loading state dan error state.

import 'package:flutter/material.dart';

/// Foto resep dari internet, lengkap dengan loading state dan error state.
class RecipeImage extends StatelessWidget {
  const RecipeImage({super.key, required this.url, this.cacheWidth});

  final String url;

  /// Lebar (pixel) saat gambar di-decode. Gambar kecil cukup di-decode kecil,
  /// sehingga memory yang dipakai jauh lebih sedikit.
  final int? cacheWidth;

  @override
  Widget build(BuildContext context) {
    return Image.network(
      url,
      fit: BoxFit.cover,
      cacheWidth: cacheWidth,
      // Loading state: tampil selama gambar masih diunduh.
      loadingBuilder: (context, child, loadingProgress) {
        if (loadingProgress == null) return child; // unduhan selesai
        return ColoredBox(
          color: Theme.of(context).colorScheme.surfaceContainerHighest,
          child: const Center(child: Icon(Icons.restaurant_menu)),
        );
      },
      // Error state: tampil jika URL salah atau tidak ada koneksi.
      errorBuilder: (context, error, stackTrace) {
        return Image.asset('assets/images/placeholder.png', fit: BoxFit.cover);
      },
    );
  }
}

class RecipeTile extends StatelessWidget {
  const RecipeTile({super.key, required this.recipe});

  final Recipe recipe;

  @override
  Widget build(BuildContext context) {
    // watch: widget ini ikut rebuild saat daftar favorit berubah
    final isFavorite = context.watch<FavoriteProvider>().isFavorite(recipe);

    return ListTile(
      leading: ClipRRect(
        borderRadius: BorderRadius.circular(8),
        child: SizedBox(
          width: 56,
          height: 56,
          // 56 dp x 3 (kepadatan layar umum) = 168 pixel
          child: RecipeImage(url: recipe.image, cacheWidth: 168),
        ),
      ),
      title: Text(recipe.name),
      subtitle: Text(
        '${recipe.cuisine} • ${recipe.totalTimeMinutes} menit • ★ ${recipe.rating}',
      ),
      trailing: IconButton(
        icon: Icon(
          isFavorite ? Icons.favorite : Icons.favorite_border,
          color: isFavorite ? Colors.red : null,
        ),
        // read: di dalam callback cukup "membaca", tidak perlu listen
        onPressed: () => context.read<FavoriteProvider>().toggle(recipe),
      ),
      onTap: () => Navigator.push(
        context,
        MaterialPageRoute(builder: (context) => DetailPage(recipe: recipe)),
      ),
    );
  }
}

                  child: Padding(
                    padding: const EdgeInsets.only(right: 8),
                    child: ChoiceChip(
                      label: const Text('Semua'),
                      selected: _cuisine == null,
                      onSelected: (_) => setState(() => _cuisine = null),
                    ),
                  ),
                ),
                for (final c in cuisines)
                  Center(
                    child: Padding(
                      padding: const EdgeInsets.only(right: 8),
                      child: ChoiceChip(
                        label: Text(c),
                        selected: _cuisine == c,
                        onSelected: (_) => setState(() => _cuisine = c),
                      ),
                    ),
                  ),
              ],
            ),
          ),
          // list/grid yang mengisi sisa layar dibungkus Expanded
          Expanded(
            child: _isGrid ? _buildGrid(filtered) : _buildList(filtered),
          ),
        ],
      ),
    );
  }

  Widget _buildList(List<Recipe> recipes) {
    return ListView.builder(
      itemCount: recipes.length,
      itemBuilder: (context, index) {
        return RecipeTile(recipe: recipes[index]);
      },
    );
  }

  Widget _buildGrid(List<Recipe> recipes) {
    return GridView.builder(
      padding: const EdgeInsets.all(8),
      gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
        crossAxisCount: 2,
        mainAxisSpacing: 8,
        crossAxisSpacing: 8,
        childAspectRatio: 3 / 4, // lebar : tinggi
      ),
      itemCount: recipes.length,
      itemBuilder: (context, index) {
        return RecipeGridCard(recipe: recipes[index]);
      },
    );
  }
}

import 'package:resepku/widgets/recipe_image.dart';

class FavoritePage extends StatelessWidget {
  const FavoritePage({super.key});

  Future<void> _confirmClear(BuildContext context) async {
    final ok = await showDialog<bool>(
      context: context,
      builder: (dialogContext) => AlertDialog(
        title: const Text('Hapus semua favorit?'),
        content: const Text('Seluruh resep favorit akan dihapus dari daftar.'),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(dialogContext, false),
            child: const Text('Batal'),
          ),
          FilledButton(
            onPressed: () => Navigator.pop(dialogContext, true),
            child: const Text('Hapus'),
          ),
        ],
      ),
    );
    if (ok == true && context.mounted) {
      context.read<FavoriteProvider>().clear();
    }
  }

  @override
  Widget build(BuildContext context) {
    final isEmpty = context.watch<FavoriteProvider>().count == 0;

    return Scaffold(
      appBar: AppBar(
        title: const Text('Favorit Saya'),
        actions: [
          TextButton.icon(
            onPressed: isEmpty ? null : () => _confirmClear(context),
            icon: const Icon(Icons.delete_sweep),
            label: const Text('Hapus semua'),
          ),
        ],
      ),
      body: Consumer<FavoriteProvider>(
        builder: (context, favorite, child) {
          if (favorite.count == 0) {
            return const Center(
              child: Text(
                'Belum ada resep favorit.\nTekan ikon hati di daftar resep.',
                textAlign: TextAlign.center,
              ),
            );
          }
          final items = favorite.items;
          return ListView.separated(
            itemCount: items.length,
            separatorBuilder: (context, index) => const Divider(height: 1),
            itemBuilder: (context, index) {
              final recipe = items[index];
              return Dismissible(
                // key unik dan stabil: id resep, bukan index
                key: ValueKey(recipe.id),
                direction: DismissDirection.endToStart,
                background: Container(
                  color: Colors.red,
                  alignment: Alignment.centerRight,
                  padding: const EdgeInsets.only(right: 16),
                  child: const Icon(Icons.delete, color: Colors.white),
                ),
                onDismissed: (direction) {
                  favorite.toggle(recipe);
                  ScaffoldMessenger.of(context).showSnackBar(
                    SnackBar(content: Text('${recipe.name} dihapus dari favorit')),
                  );
                },
                child: ListTile(
                  leading: ClipRRect(
                    borderRadius: BorderRadius.circular(8),
                    child: SizedBox(
                      width: 56,
                      height: 56,
                      child: RecipeImage(url: recipe.image, cacheWidth: 168),
                    ),
                  ),
                  title: Text(recipe.name),
                  subtitle: Text(recipe.cuisine),
                  trailing: IconButton(
                    icon: const Icon(Icons.delete_outline),
                    onPressed: () => favorite.toggle(recipe),
                  ),
                ),
              );
            },
          );
        },
      ),
    );
  }
}

D. Kesimpulan

Kesimpulan dari praktikum ini adalah saya telah memahami cara menampilkan data dan gambar pada Flutter secara efisien. Asset gambar dan custom font didaftarkan di pubspec.yaml dan cocok untuk file yang harus selalu tersedia seperti logo, sedangkan foto resep yang bersumber dari internet ditampilkan dengan Image.network yang dilengkapi loadingBuilder, errorBuilder, dan cacheWidth agar aplikasi tetap ringan dan tidak menampilkan error ketika koneksi terputus. ListView.builder dan GridView.builder membuat item secara lazy sehingga efisien, dan pergantian tampilan list dan grid cukup memakai setState karena hanya dibutuhkan oleh HomePage, tanpa mengganggu state favorit di Provider yang tetap sinkron di semua tampilan. Aplikasi ResepKu berhasil mengimplementasikan logo, font Poppins, foto resep dengan loading dan error state, tampilan grid, foto besar di halaman detail, filter cuisine, serta halaman Favorit yang lebih rapi dengan Dismissible.
